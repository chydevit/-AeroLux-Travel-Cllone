# AeroLux Travel

A luxury business & first-class flight booking site built with **Next.js 14** (App Router) and **Tailwind CSS**.

## Prerequisites

- [Node.js](https://nodejs.org/) **18.17 or newer**
- npm (bundled with Node.js)

## Clone & Run

```bash
# 1. Clone the repository
git clone https://github.com/chydevit/-AeroLux-Travel-Cllone.git
cd -AeroLux-Travel-Cllone

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server with hot reload |
| `npm run build` | Create an optimized production build |
| `npm run start` | Run the production build (requires `npm run build` first) |
| `npm run lint` | Run ESLint |

## Production

```bash
npm run build
npm run start
```
